# Lô Alves · Harmonização Facial & Corporal — site

Site estático (HTML + CSS + JS puro), pronto pra Vercel sem build.

Tudo que muda fica no topo do `script.js`:
- `WA_NUMERO` — WhatsApp (com ele as mensagens vão prontas; sem ele usa o link da bio `bit.ly/LoAlves` e copia a mensagem)
- `CIDADES` — cidades, endereços e link do mapa (o botão "Ver no mapa" aparece quando houver endereço)
- `RESULTADOS` — pares de antes/depois do comparador
- `PROCEDIMENTOS` — cards e detalhes (indicação, benefícios, regiões, informação importante)
- `DEPOIMENTOS` — depoimentos reais; nome e foto só aparecem com `autorizado: true`
